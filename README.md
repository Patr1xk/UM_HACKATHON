## 🎨 Figma Prototype: ProcrastiNation (UM Hackathon)

Check out our interactive UI prototype for the **ProcrastiNation** app, designed for the UM Hackathon.

🔗 [View Figma Prototype](https://www.figma.com/proto/Cy82iqRhUwlBoIb4i0QmBm/UM-Hackathon---ProcrastiNation?node-id=0-3131&t=WA6LKjzbzXuxhpCt-1&starting-point-node-id=17%3A1281)

This prototype showcases the user interface flow and design of the application. It includes:

- 🧠 Onboarding screens  
- 📅 Task & time management features  
- 📈 Productivity tracking  
- 👥 Group collaboration tools  

Designed with a focus on **usability**, **minimalism**, and **student productivity**.
